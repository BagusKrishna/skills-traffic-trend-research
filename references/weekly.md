# Weekly scan

Use for weekly, minggu ini, last week, or a 7-day range.

- `this week/minggu ini`: Monday through now in the user's timezone; compare aligned elapsed days in the previous week when possible.
- `last week/minggu lalu`: the previous complete Monday–Sunday calendar week.
- `last 7 days/weekly` without calendar wording: seven complete local days ending yesterday; use an exact timestamp range instead if the source only supports a rolling window and disclose it.
- Default comparison: the immediately preceding matching 7-day window, plus a 30–90 day background.

Look for subjects recurring across several days and more than one underlying dataset. Combine Google Trends, social/community observations, and emerging products or competitor traffic. Track whether the interest is still building, holding, fading, or unknown; do not calculate a slope without actual observations.

Name the recurring user problem, particularly organizer workflows, creator tasks, game planning, file operations, or collaborative activities. Check whether a weekly return trigger exists and how users would discover or share the tool.

Source periods may differ: platform 7-day views and an SEO tool's monthly estimate remain separate evidence rows. Present observed persistence, plausible app candidates, and a concrete small experiment for the strongest candidate.

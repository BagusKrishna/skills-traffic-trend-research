# Daily scan

Use for hari ini, today, now, daily, and the last 24 hours.

- `today/hari ini`: local midnight through the current client time; show that the day is incomplete.
- `last 24 hours`: the rolling 24-hour window through now. Keep this distinct from a calendar day.
- Default comparison: the equivalent hours yesterday when available. Use a 7–30 day background to distinguish an isolated event from an ongoing need.

Start with Google Trends Trending Now in the requested market and current social/community pages. Open platform timestamps before quoting a live ranking. Cached search snippets and yesterday's stories cannot establish what is trending now. Follow promising subjects into recent questions, original announcements, and direct product pages.

Label each signal as an event spike, recurring daily task, new behavior to watch, or insufficient evidence. For app ideas, explain whether the user task survives after the news event. A game release can suggest a durable planning/build tool; the release headline alone does not prove that tool's demand.

If a source offers only 7/30-day data, use it as background and retain that label. If today's primary data cannot be accessed, state that the live daily ranking is unverified; provide recent candidates only as watchlist items.

Output a time-stamped snapshot, promising tasks with sources, and a next observation or validation step. Do not claim a stable opportunity from a single day's movement.
